03

Product Recommendation System

Collaborative Filtering · SVD · Customer Personalization

Hybrid recommendation engine combining user-based collaborative filtering (Pearson similarity) with content-based filtering on product attributes (organic, vegan, gluten-free tags). SVD matrix factorization via the Surprise library. Cold-start users served via dietary preference fallback. Proof-of-concept REST API serves top-5 recommendations per user.

Retail KPI Dashboard

Power BI · DAX · Executive Reporting · Data Storytelling

Executive-level retail dashboard with four report pages: Sales Overview, Department Deep Dive, Customer Trends, and Inventory & Shrink.
